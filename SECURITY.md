# Security policy

Please report suspected vulnerabilities privately through GitHub Security
Advisories: open this repository's **Security** tab and choose **Report a
vulnerability**. Please do not open a public issue for anything you believe
is security-sensitive.

This crate is maintained by one person as a side project, so there is no hard
response-time guarantee — but security reports are triaged promptly and take
priority over all other work. You will receive an acknowledgement, an
assessment or a fix, and credit in the resulting advisory if you want it.
